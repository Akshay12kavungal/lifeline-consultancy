# Life Line Consultancy Website

A premium, responsive React website for Life Line Consultancy.

## Getting Started

### Prerequisites
- Node.js 16+ installed

### Installation & Run

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

### Build for Production

```bash
npm run build
```

## Sections
- **Hero** – Full-screen landing with CTA buttons
- **Stats Bar** – 12K+ students, 98% success rate, etc.
- **Courses** – 6 consultancy programs with hover effects
- **About** – Team, animated progress bars, stats
- **Testimonials** – 4 alumni stories
- **FAQ** – Accordion-style questions
- **CTA Banner** – Call-to-action section
- **Contact** – Form + contact details
- **Footer** – Full multi-column footer

## Tech Stack
- React 18
- CSS-in-JS (inline styles + style tags)
- Google Fonts (Playfair Display + Lato)
- IntersectionObserver for scroll animations
